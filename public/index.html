Raw CLI args appended verbatim to the encoder command.
cpu forces software nlmeans. auto probes Vulkan first, then OpenCL, falling back to CPU. vulkan / opencl force that backend (still falls back to CPU if probe fails).
s = strength [1.0 – 30.0], p = patch size (odd) [1 – 99], r = research size (odd) [1 – 99]. Larger values denoise more aggressively but cost more time.
strength = max change per pixel [0.51 – 64], radius = neighbourhood size [8 – 32].
